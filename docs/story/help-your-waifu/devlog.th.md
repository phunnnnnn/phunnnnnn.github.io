เกมนี้เริ่มทำใน Roblox Studio มาก่อนแล้ว (ตัวเกมสร้างเมื่อธันวาคม 2568) มีระบบแบก ฐาน และการเซฟเวอร์ชันแรกอยู่ วันที่ 22 ตุลาคม 2569 ผมย้ายโปรเจกต์เข้า Rojo และ Git และนี่คือช่วงพัฒนานั้น: 45 commit ใน 6 วัน ตั้งแต่ commit แรกจนเปิดให้เล่น

### ไทม์ไลน์

- **22 ต.ค. วางรากฐาน:** ตั้งค่า Rojo และ ProfileStore ตัวสร้างด่าน obby ตารางความหายากและจุดเกิด waifu รายได้และรายได้ตอนออฟไลน์ HUD แสดงเงิน เช็คพอยต์และการเกิดใหม่เมื่อตก จากนั้นระบบเลเวล ร้านกล่องสุ่ม สินค้า Robux เครื่องมือแอดมิน และบล็อกที่ทำให้ตาย
- **23 ต.ค. ทำให้เป็นเกม:** ระบบดีไซน์ UI สำหรับทุกหน้าจอ แก้การแบกปลอม เสียงประกอบ คำแนะนำผู้เล่นใหม่ ป้ายร้านค้าและป้ายขาย สายพาน และเขียนระบบฐานใหม่: เลิกใช้แท่นโชว์ เปลี่ยนเป็น waifu เดินเล่นรอบบ้านหลังคาแดง
- **24 ต.ค. หน้าตาแบบเกมซิมูเลเตอร์:** พื้นผิวลายตัวต่อ ชุดไอคอน HUD ที่ปรับขนาดตามจอ ป้ายชื่อและตัวเลขรายได้เด้งขึ้น ทางแยก 4 ทางจากจุดเริ่ม และเขียนกฎ UI เป็นเอกสาร
- **27 ต.ค. วันเปิดเกม:** waifu ปริศนา พรมวิเศษ วาร์ปด่วน หน้าจอมือถือ ID Robux จริง และภาพในร้าน จากนั้นแก้ช่องโหว่ความปลอดภัย 2 จุด ลบของที่หลงเหลือจากช่วงพัฒนา collision group การป้องกันระหว่างสร้างด่านใหม่ PolicyService ชิ้นส่วนไม่ซ้ำ แก้ปัญหา streaming ราคาการหยิบ ทำแผงแอดมินใหม่ และการปีนแบบขี่หลัง

### โครงสร้างโค้ด

ไฟล์ Luau 56 ไฟล์ ประมาณ 9,200 บรรทัด ไม่นับไลบรารี ProfileStore ซิงก์เข้า Studio ด้วย Rojo:

```
src/
  ReplicatedStorage/Shared/             9 โมดูล: ตารางค่าต่างๆ + ชุด UI
  ServerScriptService/                  เซอร์วิสฝั่งเซิร์ฟเวอร์: obby, จุดเกิด,
    BaseService/                        เงิน, ร้านค้า, Robux, แอดมิน, เช็คพอยต์...
    CarryWaifuService/
    DataService/
  StarterPlayer/StarterPlayerScripts/   สคริปต์ฝั่งผู้เล่น 18 ไฟล์: HUD, ร้านค้า,
                                        waifu, วาร์ปด่วน, วิ่งเร็ว, เมนูแอดมิน
```

- **เซอร์วิสฝั่งเซิร์ฟเวอร์เป็นเจ้าของเกม** แต่ละตัวสร้าง remote ของตัวเอง (ซื้อกล่อง ซื้อเลเวล วาง waifu หยิบ waifu…) และตรวจทุกคำขอ
- **ฝั่งผู้เล่นอ่านค่าจาก attribute เป็นหลัก** ข้อมูลที่ใช้ร่วมกันอย่างเวลาสร้างด่านรอบถัดไป Luck Boost เลเวลที่ปลดล็อก pass และรายได้ เก็บเป็น attribute ทำให้ UI อัปเดตเองโดยไม่ต้องมี remote เพิ่ม
- **แท็กเชื่อมโลกในเกมกับโค้ด** เช็คพอยต์ บล็อกที่ทำให้ตาย กำแพงเลเวล และจุดวาง waifu หาเจอด้วยแท็กของ CollectionService การสร้างด่านใน Studio จึงไม่ต้องแก้โค้ด
- **ตัวเลขอยู่ในตาราง** ความหายาก รายได้ ของแต่งตัว และไอเทม Robux เป็นตารางค่าธรรมดาใน `Shared` ปรับสมดุลได้ง่าย

### การเซฟ

ProfileStore โหลดและเซฟข้อมูลผู้เล่นแต่ละคนพร้อมล็อกเซสชัน เซฟเดียวจึงเปิดบนสองเซิร์ฟเวอร์พร้อมกันไม่ได้ เซฟจาก DataStore เก่าของเกมจะถูกย้ายมาครั้งเดียว เกมเซฟทันทีหลังการซื้อทุกครั้ง และใบเสร็จ Robux จำ ID การซื้อ 50 รายการล่าสุด การซื้อหนึ่งครั้งจึงไม่มีทางได้ของสองรอบ

### ตัวสร้างด่าน obby

ชิ้นส่วนที่ทำมือของแต่ละระดับความยากเก็บไว้บนเซิร์ฟเวอร์ ตัวสร้างจะต่อชิ้นส่วนเข้าด้วยกันตามจุดเชื่อม วางเช็คพอยต์ทุกรอยต่อ และแตกทางแยกจากชิ้นหลักแต่ละชิ้นไปสิ้นสุดที่จุดวาง waifu ทุกชิ้นถูกเช็คว่าทับกันไหม ทางที่วางไม่พอดีจะถูกตัดให้สั้นลง แต่ละเลเวลลองจัดวาง 10 แบบแล้วเก็บแบบที่ดีที่สุด ชิ้นส่วนแจกจากกองที่สับแล้วจึงไม่ซ้ำในเลนเดียวกัน และใช้ seed ทำให้สร้างด่านเดิมซ้ำได้ทุกเมื่อ

### ระบบกันโกง

- หยิบได้เฉพาะในระยะ 12 stud เฉพาะเลเวลที่ปลดล็อกแล้ว และหยิบ waifu ที่คนอื่นถืออยู่ไม่ได้
- กลับถึงบ้านเร็วกว่าที่ผู้เล่นวิ่งได้ (60 stud ต่อวินาที บวกระยะเผื่อ) จะไม่ได้รางวัล
- เช็คระยะที่ร้านค้า (25 stud) และกำแพงเลเวล (40 stud) และไอเทมที่แบกต้องตรงกับที่ถืออยู่จริง

### แผงแอดมิน

ช่องผู้เล่น 8 ช่องพร้อมรูปอวาตาร์ และแท็บสำหรับผู้เล่น waifu เซฟ การเคลื่อนที่ โลก และอีเวนต์ รวมคำสั่ง 38 คำสั่ง ตัวแก้เซฟที่ต้องกดยืนยันซ้ำก่อนทำสิ่งที่ลบข้อมูล และอีเวนต์ "แอดมินป่วน" อย่างฝนเงิน ฝน Mythic และแรงโน้มถ่วงต่ำ
