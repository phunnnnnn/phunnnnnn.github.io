Help Your Waifu เป็นโปรเจกต์ที่ทำกัน 2 คน เพื่อนเป็นคนนำด้านการออกแบบเกมและออกแบบด่าน ส่วนผมดูแลทุกอย่างที่ทำให้เกมทำงานได้ ทั้งโค้ดและ UI

### วิธีที่ผมทำงาน

ผมสร้างเกมนี้โดยใช้ **Claude Code** เป็นผู้ช่วยเขียนโค้ด AI หน้าที่ของผมคือตัดสินใจว่าจะสร้างอะไรและควรให้ความรู้สึกแบบไหน แบ่งงานออกเป็นระบบต่างๆ ทดสอบทุกการเปลี่ยนแปลงใน Roblox Studio (ทั้งบน PC และตัวจำลองมือถือ) แล้วส่งกลับไปแก้จนกว่าจะถูกต้อง การตัดสินใจอย่างการแบกแบบขี่หลังเพื่อปีนบันได สไตล์ UI ลายตัวต่อ และหน้าตาแผงแอดมิน มาจากผมเอง

### สิ่งที่ผมสร้าง

- **ด่าน obby แบบสุ่ม:** ตัวสร้างด่านที่ต่อชิ้นส่วนที่ทำมือเข้าด้วยกันเป็น 8 เลเวล และสร้างใหม่ทุก 5 นาที โดยผู้เล่นปลอดภัยระหว่างที่ด่านกำลังสร้าง
- **waifu ปริศนาและการแบก:** การเกิด การสุ่มระดับความหายาก การหยิบ การแบก (รวมการปีนแบบขี่หลัง) การทำตก และจุดเช็คพอยต์
- **ฐาน:** การจับจองที่ดิน บ้าน และ waifu ที่เดินเล่นในสนามพร้อมหาเงิน
- **ระบบเศรษฐกิจ:** รายได้ รายได้ตอนออฟไลน์ การขาย กำแพงเลเวล Luck Boost และอีเวนต์ Legendary
- **ร้านค้าและร้าน Robux:** กล่องสุ่มที่ใช้สต็อกร่วมกันทั้งเซิร์ฟเวอร์ game pass 4 แบบ และ developer product 7 แบบ ทำตามกฎของ Roblox เรื่องไอเทมสุ่มแบบเสียเงิน
- **การเซฟ:** ProfileStore พร้อมระบบล็อกเซสชัน การย้ายเซฟจากระบบเก่าของเกมครั้งเดียว และใบเสร็จ Robux ที่ไม่มีทางได้ของซ้ำสองครั้ง
- **ระบบกันโกง:** เซิร์ฟเวอร์ตรวจทุกการหยิบ การซื้อ และการแบก
- **แผงแอดมิน:** คำสั่ง 38 คำสั่ง ตัวแก้เซฟ และอีเวนต์สดอย่างฝนเงินและแรงโน้มถ่วงต่ำ
- **UI:** ชุด UI กลาง (สี ปุ่ม ไอคอน เสียง) ที่ทุกหน้าจอสร้างขึ้นจากชุดนี้ ในสไตล์เกมซิมูเลเตอร์ที่ใช้บนมือถือได้ด้วย

### เตรียมก่อนเปิดให้เล่น

ก่อนเปิดเกม ผมไล่หาทางทำให้เกมพังทุกทาง ปิดช่องโหว่วาร์ปข้ามกำแพง และช่องที่ผู้เล่นอีกคนขโมย waifu ของคนอื่นได้ ลบปุ่มลัดดีบักที่หลงเหลืออยู่ซึ่งทำให้ผู้เล่นคนไหนก็ดึงข้อมูลเซฟออกมาได้ จากนั้นเปลี่ยนไอเทม Robux ทุกชิ้นเป็น ID จริง และทำให้ร้านค้าทำตาม PolicyService ของ Roblox
