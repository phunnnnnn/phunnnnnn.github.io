### How the obby is built

![Looking down an obby lane that runs between blocky mountains](assets/projects/help-your-waifu/obby-mountains-overview.jpg)

- Hand-built pieces snap together, with a checkpoint on every joint
- Each main piece branches a side path ending in a waifu square
- Each level gets 10 layout attempts, and the best one is kept

### Admin panel

![The admin panel open on the player tab, with cash and level buttons](assets/projects/help-your-waifu/admin-v2-player.jpg)

- 8 player slots with avatars, and six tabs from player to events
- 38 commands in all, plus a save editor
- Destructive save edits need a second click
- Admin abuse events like cash rain, Mythic rain and low gravity
