Lost Dept เป็นโปรเจกต์ที่ทำคนเดียว ออกแบบและเขียนโค้ดเอง โดยมี Claude Code ช่วย

### วิธีที่ผมทำงาน

Claude Code เป็นผู้ช่วยเขียนโค้ด AI และเขียนโค้ดส่วนใหญ่ ผมทำงานทีละการตัดสินใจ: ตั้งคำถาม ดูตัวเลือก ผมตัดสินใจ ร่าง แล้วผมอนุมัติ และไม่มีอะไรถูก commit ถ้าผมไม่สั่ง ภาพพิกเซล เสียงประกอบ และเพลงก็สร้างจากสคริปต์เช่นกัน ทั้งหมดยกเว้นหอยทากปล่องร้อนที่วาดด้วยมือ

### สิ่งที่ผมสร้าง

- **สัตว์เลี้ยง:** 20 ตัว แต่ละตัวมีสกิลของตัวเอง มี AI ที่เลือกการกระทำถัดไป 10 ครั้งต่อวินาทีจากลำดับความสำคัญ มีระดับความหายากและเลเวล
- **เวฟและบอส:** ตัวปล่อยเวฟที่ตั้ง HP ศัตรูตามดาเมจที่ทีมของคุณน่าจะทำได้ ศัตรู 3 แบบ มินิบอส และบอส 5 ตัวที่มีชุดท่าโจมตีและการ์ดเปิดตัวของตัวเอง
- **ร้านค้า:** ลากวางไอเทม การ์ดสัตว์เลี้ยงที่บอกความหายาก เลเวล และ XP และการสุ่มร้านใหม่แบบเสียเงิน
- **ความรู้สึกตอนเล่น:** ระบบอีเวนต์ที่เล่นเสียงและการสั่นจอทั้งหมดจากที่เดียว การหยุดภาพชั่วขณะเมื่อโดนแรงๆ เชเดอร์น้ำและแสง เมนูหยุดเกม บทสอนเล่น และลูกศรชี้ศัตรูที่อยู่นอกจอ
- **คุณภาพ:** เทสอัตโนมัติ 15 ชุด และบอทที่เล่นเกมเองเพื่อใช้ปรับสมดุล

### เปิดตัว

Lost Dept เปิดให้เล่นบน itch.io เมื่อวันที่ 21 ตุลาคม 2569 ทั้งบนเบราว์เซอร์และ Windows เวอร์ชันเว็บทำงานแบบเธรดเดียว จึงเล่นบน itch.io ได้โดยไม่ต้องตั้งค่าเซิร์ฟเวอร์พิเศษ
