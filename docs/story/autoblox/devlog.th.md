### โครงสร้าง

```
src/
  lobby/    ห้อง โค้ด ข้อความข้ามเซิร์ฟเวอร์ การเริ่มแมตช์ + UI ห้อง
  game/     แมตช์: เอนจินการต่อสู้ รอบ ระบบเงิน ม้าหมุน ของดรอป การอัญเชิญ
            คลังตัวละคร ออกเมนต์ + ตัววาดภาพฝั่งผู้เล่นและ UI
  shared/   ข้อมูลตัวละคร คอมโบ ไอเทม การวาดภาพการต่อสู้ ค่าตั้งต้น เครือข่าย ห้อง
```

- **สอง place หนึ่งเกม** ล็อบบี้กับแมตช์เป็นคนละ place และมีโปรเจกต์ Rojo แยกกัน
- **เอนจินการต่อสู้** ทำงานทุก 0.1 วินาที และหาเส้นทางบนกริดหกเหลี่ยมทุกจังหวะ ใช้ชุดคำสั่งเดียวทั้งการต่อสู้แบบคำนวณทันทีและแบบเรียลไทม์ กติกาจึงอยู่ที่เดียว
- **ส่งการต่อสู้แบบสด** เซิร์ฟเวอร์ส่งข้อความตั้งค่าครั้งแรก ตามด้วยประมาณ 10 เฟรมต่อวินาที แล้วข้อความจบ ส่งเฉพาะผู้เล่นที่อยู่ในการต่อสู้นั้น
- **ห้องข้ามเซิร์ฟเวอร์** ข้อมูลห้องเก็บใน MemoryStore ส่วน MessagingService แค่บอกว่า "มีอะไรเปลี่ยน" แล้วแต่ละเซิร์ฟเวอร์ไปอ่านข้อมูลใหม่เอง การเริ่มแมตช์จะจองเซิร์ฟเวอร์แล้ววาร์ปทั้งปาร์ตี้ ลองใหม่หนึ่งครั้งและย้อนกลับถ้าล้มเหลว
- **ตรวจชนิดข้อมูลแบบเข้มงวด** 107 จาก 111 ไฟล์ใช้โหมด strict ของ Luau
