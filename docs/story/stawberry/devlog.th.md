Stawberry สร้างขึ้นใน 10 วันช่วงสิงหาคม 2569 และซิงก์เข้า Roblox Studio ด้วย Rojo แผนที่อยู่ในไฟล์ place ใน repo และมี pre-commit hook ที่ทำให้แผนที่ติดไปกับทุก commit

### ไทม์ไลน์

- **5 ส.ค.:** โปรเจกต์ Rojo แผนที่ใน repo และวงจรตั้งแต่เมล็ดจนขายครบ: สายพาน การปลูก การเก็บเกี่ยว การ์ดราคาผลไม้ คนรับซื้อ และกระดานผู้นำ
- **6 ส.ค.:** เมล็ด 18 ชนิดที่ซื้อจากสายพาน ผลไม้แปรรูปเป็นพายที่โรงงานที่ผู้เล่นวางเอง โรงงานต่อกันเป็นสายการแปรรูป 5 ขั้น คนงาน NPC ที่ปลูก แปรรูป และขาย จากนั้นเปลี่ยนเป็นการจ้างจากรายชื่อหมุนเวียนแทนการแจกฟรี
- **7 ส.ค.:** โรงงานเลเวลที่ได้จากเครื่องสุ่มของผู้เล่นแต่ละคน
- **14 ส.ค.:** เลเวลของสายพานเมล็ด และร้านสำหรับซื้อ

### โครงสร้างโค้ด

```
src/
  shared/   ReplicatedStorage.Shared      ค่าตั้งต้น + กฎที่ใช้ร่วมกัน: เมล็ด พืช
                                          การวางในฟาร์ม กริดโรงงาน โมเดล
  server/   ServerScriptService.Server    เซอร์วิส: กระเป๋า ฟาร์ม โรงงาน
                                          เครื่องสุ่ม อัปเกรด การขาย คนงาน
  client/   StarterPlayerScripts.Client   การถือไอเทม ตัวแสดงตำแหน่ง การ์ดราคา
                                          หน้าต่างขาย ร้านอัปเกรด กระดานผู้นำ
```

- **เซอร์วิสเริ่มทำงานตามลำดับ** กระเป๋าเริ่มก่อน เพราะเซอร์วิสอื่นต้องให้ของเข้ากระเป๋า คนงานเริ่มท้ายสุด เพราะต้องรอให้ฟาร์ม โรงงาน และคนรับซื้อพร้อมก่อน
- **คนงานทำงานบนเซิร์ฟเวอร์ทั้งหมด** การจ้างและเลิกจ้างเป็นแค่ proximity prompt ธรรมดา จึงไม่มี remote ให้โกง คนงานแต่ละคนเดินเป็นวง: เก็บผลที่สุก นำไปโรงงาน รับสินค้า แล้วไปขาย เหรียญเข้ากระเป๋าเจ้าของ
- **คนงานเป็นตัวละคร R6 จริง** สร้างทีละชิ้นแทนการสร้างจากข้อมูลอวาตาร์ การจ้างจึงไม่ต้องรอระบบอวาตาร์ของ Roblox และท่าเดินคำนวณจากระยะที่เดินจริง ขาจึงหยุดเมื่อตัวหยุด
- **อัปเกรดเป็นข้อมูล** เครื่องสุ่มแต่ละสายคือชื่อ รายการราคา และฟังก์ชัน 3 ตัว การเพิ่มสายใหม่คือการเพิ่มอีกหนึ่งรายการในตาราง
