### Same rules on both sides

- The previews and the shop read the same code as the server
- So a preview never promises a spot the server refuses
- And the shop never shows odds the server won't roll

### Never lose a player's stuff

- Harvests and factories keep the item until the player really has it
- Coins change in only two places: one add and one spend function
- Buying a seed checks for backpack room before charging

### Two hard lessons

- With 18 seed species, checking by name would miss all but one
- So seeds are recognised by an attribute instead of their name
- A broken cosmetic module once silently disabled planting
- Now each cosmetic module starts on its own, behind its own error guard
