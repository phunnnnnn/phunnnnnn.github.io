### How a build is made

1. Export the model from Blender as DMX
2. Compile the materials and model with the Reduced CSDK 12
3. Final compile in CS2 Workshop Tools, which links Mina's animations
4. Stage the files with Python scripts
5. Pack a VPK with Source 2 Viewer and load it with the Mod Manager
